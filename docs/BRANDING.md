ฟอนต์ชุดเดียวกับเว็บร้าน: **Playfair Display** (หัวข้อและตัวเลข), **Lora** (เนื้อความ),

เพราะสองฟอนต์แรกไม่มีสระและวรรณยุกต์ไทย ถ้าไม่ใส่ เบราว์เซอร์จะตกไปใช้ฟอนต์ระบบและโทนจะหลุด

## การตัดสินใจเรื่องพื้นสว่าง/พื้นเข้ม

| ส่วน | โทน | เหตุผล |
|---|---|---|
| หน้าบัตรลูกค้า (`/liff`) | **พื้นมรกตเข้ม + ทอง** ตรงกับเว็บร้าน | ลูกค้าเห็นต่อจากเว็บร้านและเปิดในแอป LINE ต้องรู้สึกเป็นแบรนด์เดียวกัน |
| แอปพนักงาน | **พื้นครีม/มิ้นต์ + มรกตเป็นสีเน้น** | เป็นเครื่องมือที่ใช้ทั้งวันกลางร้านที่แสงจ้า พื้นเข้มทั้งจอกับ serif ตัวเล็กอ่านยากและกดพลาดง่าย |

ทั้งสองแบบใช้เฉพาะห้าสีในพาเลตต์ ไม่มีการเพิ่มสีใหม่ สีสถานะ (เตือน/ผิดพลาด/สำเร็จ)
ไล่มาจากทองและมรกตของแบรนด์ ไม่ใช่แดง/เขียวสดแบบค่าเริ่มต้นของเบราว์เซอร์

## ไฟล์ที่เกี่ยวข้อง

- `wwwroot/css/brand.css` — โทเคนกลาง โหลดก่อนไฟล์อื่นเสมอ
- `wwwroot/css/app.css` — แอปพนักงาน (คงชื่อคลาสเดิมทั้งหมด ไม่ต้องแก้ markup)
- `wwwroot/css/liff.css` — หน้าบัตรลูกค้า ทับค่าบนพื้นเข้ม
- `wwwroot/icons/favicon.svg` — โลโก้รวงข้าว คัดจาก `CoffeeTemplate/public/images/favicon.svg`
- `wwwroot/icons/icon-192.png`, `icon-512.png` — ไอคอน PWA วาดจากโลโก้เดียวกัน
  (สคริปต์ที่ใช้วาดอยู่ใน scratchpad ของเซสชัน ถ้าต้องวาดใหม่ให้ render จาก `icon.svg`)
- `manifest.webmanifest` — ชื่อ MInDCoffee, theme/background `#0f3d34`

## บั๊กที่เจอตอนตรวจด้วยตาและแก้แล้ว

1. **กล่อง "ลูกค้าที่เลือก" โผล่ทั้งที่ยังไม่ได้เลือก** — `.chosen-customer { display: flex }`
   มี specificity สูงกว่า `[hidden] { display: none }` ของเบราว์เซอร์ แก้ด้วยการประกาศ
   `[hidden] { display: none !important; }` ไว้บนสุดของ `app.css` ครั้งเดียว
2. **ลิงก์ที่ทำเป็นปุ่มมีขีดเส้นใต้** — เพิ่ม `a.btn, a.nav-link { text-decoration: none }`
3. **แถบบนตกสองบรรทัดบนแท็บเล็ต** เมื่อผู้จัดการเห็นเมนูครบหกอัน
   แก้ให้เมนูเลื่อนแนวนอนแทนการตัดบรรทัด และซ่อนป้าย role ที่จอแคบ

ตรวจด้วยการวัดจริงบนหน้าเว็บ ไม่ใช่แค่ดูภาพ: พื้นหลัง `rgb(247,246,241)`,
หัวข้อเป็น Playfair Display, เนื้อความเป็น Lora + Noto Serif Thai,
ปุ่มหลัก `rgb(200,169,106)`, แถบบนสูง 62px แถวเดียว

## เปลี่ยนชื่อร้าน (ใช้เป็น template ได้)

ชื่อร้านมี **แหล่งเดียว** คือ `shop_settings.shop_name` ในฐานข้อมูล
เปลี่ยนที่ **ตั้งค่า → ชื่อร้าน** ที่เดียว แล้วทุกจุดเปลี่ยนตามทันทีโดยไม่ต้องแก้โค้ดหรือ deploy ใหม่

จุดที่ใช้ชื่อร้าน (ทดสอบแล้วว่าตามครบทุกจุด)

| ที่ | มาจาก |
|---|---|
| ชื่อบนแท็บเบราว์เซอร์ทุกหน้า | `_Layout.cshtml` → `Settings.GetShopNameAsync()` |
| โลโก้ + ชื่อบนหน้าล็อกอิน | `Pages/Staff/Login.cshtml` |
| หัวบัตรลูกค้าใน LIFF และหน้า PDPA | `Pages/Liff/Index.cshtml`, `Privacy.cshtml` |
| ชื่อตอนติดตั้ง PWA ลงหน้าจอโฮม | `GET /manifest.webmanifest` สร้างสดจากฐานข้อมูล |
| ข้อความ push แจ้งแต้มทาง LINE | `LinePushService.BuildEarnMessage` |
| ชื่อผู้รับเงินใน QR พร้อมเพย์ | ช่องแยกที่ ตั้งค่า → ชื่อผู้รับเงินใน QR (ต้องเป็นอักษรอังกฤษ) |

`manifest.webmanifest` **ไม่ใช่ไฟล์ตายตัวแล้ว** แต่เป็น endpoint ที่ประกอบจากชื่อร้าน
และไม่ถูกแคชใน service worker เพื่อให้เปลี่ยนชื่อแล้วเห็นผลทันที
ชื่อย่อบนไอคอนตัดให้ไม่เกิน 12 ตัวอักษรโดยนับ "หน่วยที่คนอ่าน" (`StringInfo`)
ไม่ใช่ `char` ของ .NET เพราะชื่อไทยที่มีสระหรือวรรณยุกต์จะถูกตัดกลางตัวอักษร

สำหรับการติดตั้งร้านใหม่ตั้งแต่ต้น: ตั้ง `Shop:Name` ใน `appsettings.json`
ค่านี้ใช้ตอน seed ครั้งแรกครั้งเดียว หลังจากนั้นฐานข้อมูลเป็นเจ้าของค่า

ถ้าจะใช้เป็น template ให้ร้านอื่น เปลี่ยนสามอย่างนี้
1. ชื่อร้าน — หน้าตั้งค่า (หรือ `Shop:Name` ก่อน seed)
2. สี — `wwwroot/css/brand.css` (ห้าตัวแปรบนสุด)
3. โลโก้ — `wwwroot/icons/favicon.svg` และ `icon-192/512.png`
