# Phase 3 — แลกรางวัล, แต้มหมดอายุ, เพดานแต้ม (เสร็จแล้ว)

ทำเมื่อ 22 ต.ค. 2026 หลังเจ้าของร้านตอบคำถามสุดท้ายที่ค้างใน README

## คำตอบที่ปลดล็อกงานนี้

> **`PriceCap` = เพดานราคาที่เจ้าของตั้งเองเป็นตัวเลขคงที่**
> ดูจากราคาเมนูในร้านแล้วตัดสินใจเชิงการตลาดว่าจะไม่ให้ขาดทุนเกินไป
> ไม่ได้คำนวณอัตโนมัติจากเมนูที่ลูกค้าซื้อบ่อยหรือราคาแก้วมาตรฐาน

คำถามท้าย README ตอบครบทุกข้อแล้ว

## ตารางที่เพิ่ม (migration `Phase3Rewards`)

- `redemptions` — การแลกหนึ่งครั้ง ผูกกับออเดอร์ที่มีบรรทัดรางวัล
  มี `source` (`Stamps` / `PaperCard`), `stamps_used`, snapshot ของชื่อและราคาเมนู,
  `top_up_amount`, ผู้ทำและผู้อนุมัติ
  **unique ที่ `order_id`** — หนึ่งออเดอร์แลกได้ครั้งเดียว
- `stamp_allocations` — บอกว่าแต้มที่ถูกใช้ไปตัดมาจากก้อนไหน
  ทำให้ FIFO ทำงานจริงและตรวจย้อนได้ว่าก้อนไหนถูกใช้ไปแล้ว

`StampTransaction` เพิ่ม navigation ไป `Redemption` และ `Redemption.CustomerId` เป็น null ได้
สำหรับการแลกด้วยบัตรกระดาษที่ยังไม่มีสมาชิกในระบบ

## สามโหมดรางวัล

| โหมด | เงื่อนไข |
|---|---|
| `AllItems` | แลกได้ทุกเมนูที่ยังขายอยู่ ฟรีเต็มราคา |
| `SelectedItems` | เฉพาะเมนูที่ติ๊ก "ใช้แลกรางวัลได้" ในหน้าเมนู |
| `PriceCap` | ราคาไม่เกินเพดานที่ตั้งไว้ ถ้าเกินและเปิด `AllowRewardTopUp` ลูกค้าจ่ายส่วนต่าง |

ส่วนต่างคิดเป็น `ราคาเมนู − เพดาน` พอดี เก็บเป็นยอดของออเดอร์รางวัลนั้น
แก้วที่แลกไม่ได้แต้มกลับ (`EarnsStampSnapshot = false`) ตามกฎใน README

## ตัดแต้มแบบ FIFO

`StampService.AllocateFifoAsync` เรียงก้อนต้นทางด้วย

1. ก้อนที่มีวันหมดอายุมาก่อนก้อนที่ไม่มีวันหมดอายุ
2. วันหมดอายุที่ใกล้ที่สุดก่อน
3. ถ้าเท่ากันใช้ `id` น้อยกว่าก่อน

ก้อนต้นทางคือรายการที่ `quantity > 0` ทั้งหมด (ทั้ง `Earn` และ `Adjust` ที่เพิ่มแต้ม)
ไม่ใช่แค่ `Earn` เพราะแต้มที่ย้ายมาจากบัตรกระดาษก็มีวันหมดอายุเหมือนกัน

ถ้าก้อนที่ตัดได้ไม่พอกับยอดที่ขอ จะโยน error แทนการตัดครึ่ง ๆ กลาง ๆ
เพราะแปลว่ายอดคงเหลือกับ ledger ไม่ตรงกัน ซึ่งต้องให้คนตรวจ

## แต้มหมดอายุ

`StampExpiryJob` เป็น `BackgroundService` ทำงาน **ตี 3 เวลาไทย** และ
**ตรวจทันทีตอนแอปสตาร์ต** เผื่อร้านปิดเครื่องข้ามวัน (เครื่องนี้ไม่ได้เปิด 24 ชั่วโมง)

งานนี้มองจากวันหมดอายุของแต่ละก้อน ไม่ได้จำว่าเคยรันไปแล้วกี่ครั้ง **จึงรันซ้ำได้ไม่ตัดเกิน**
(ทดสอบแล้ว: สั่งซ้ำได้ `expired = 0`) ผู้จัดการสั่งเองได้ที่ `POST /api/rewards/expire-now`

สำคัญ: ยอดใน `customer_balances` ยังรวมแต้มที่หมดอายุแต่ job ยังไม่ตัด
ตอนแลกจึงเช็กจาก **`GetUsableStampsAsync`** ซึ่งไม่นับก้อนที่หมดอายุแล้ว
ไม่ใช่เช็กจากยอดคงเหลือตรง ๆ

## เพดานแต้ม

`MaxStampsPerOrder` และ `MaxStampsPerDayPerCustomer` บังคับใช้แล้วตอนออกแต้ม
เกินได้ต่อเมื่อใส่ PIN ผู้จัดการ และบันทึก `stamp.cap_override` ใน audit log
เพดานต่อวันนับเฉพาะแต้มจากการซื้อ (`Earn`) ในวันทำการเดียวกัน

## ผลการทดสอบกับฐานข้อมูลจริง (22 ต.ค. 2026)

unit test 182 ตัวผ่านหมด (เพิ่มจาก 164 มา 18 ตัว)

| ทดสอบ | ผล |
|---|---|
| สแตมป์เกินเพดานต่อวันโดยไม่มี PIN | ถูกปฏิเสธพร้อมบอกว่าวันนี้ได้ไปแล้วเท่าไร |
| สแตมป์เกินเพดานพร้อม PIN ผู้จัดการ | ผ่าน และบันทึก override |
| แลกรางวัลโหมด `AllItems` | ใช้ 10 แต้ม ยอดเหลือ 0 ออเดอร์รางวัลถูกสร้าง |
| แลกทั้งที่แต้มไม่พอ | ถูกปฏิเสธ "ต้องมี 10 แต้ม ตอนนี้ใช้ได้ 0" |
| โหมด `PriceCap` เพดาน 50 | เมนู 45/50 แลกได้ ส่วน 55/60 แลกไม่ได้ |
| เมนูเกินเพดานตอนปิด top-up | ถูกปฏิเสธ "ราคาเกินเพดาน 50.00 บาท" |
| เปิด top-up แล้วแลกมอคค่า 60 | ผ่าน เก็บเพิ่ม **10.00 บาท** พอดี |
| ลำดับการตัดแบบ FIFO | ตัดก้อนที่ใกล้หมดอายุก่อนจริง (ดูจาก `stamp_allocations`) |
| แต้มหมดอายุ 5 จาก 8 | `usableStamps` = 3 ตั้งแต่ก่อนตัด, job ตัด 5, ยอดเหลือ 3 |
| สั่ง job ซ้ำ | `expired = 0` ไม่ตัดเกิน |
| ยกเลิกออเดอร์ที่แต้มถูกแลกไปแล้ว | **ถูก block** พร้อมบอกว่าใช้ไปแล้วกี่แต้ม |
| แลกด้วยบัตรกระดาษ | ไม่ตัดแต้ม บันทึก `source = PaperCard` พร้อมผู้อนุมัติ |
| ผลรวม ledger เทียบยอดคงเหลือ | ตรงกันทุกขั้นตอน |

## หน้าจอ

หน้าสแตมป์: พอเลือกลูกค้าแล้วระบบเช็กสิทธิ์ให้อัตโนมัติ
ถ้าแต้มยังไม่พอจะบอกว่าอีกกี่แต้ม ถ้าพอจะขึ้นรายการเมนูที่แลกได้พร้อมบอกส่วนต่างที่ต้องเก็บเพิ่ม
กดแล้วยืนยันหนึ่งครั้งก่อนตัดแต้มจริง

  และหน้าจอย้ายบัตรกระดาษพร้อมรูปถ่าย (ดู `docs/MIGRATION-PAPER-CARDS.md`)
- ปุ่มแลกด้วยบัตรกระดาษยังมีแค่ API (`POST /api/rewards/redeem-paper-card`) ยังไม่มีปุ่มบนหน้าจอ
- ยังไม่มีหน้าสรุปว่าวันนี้แลกไปกี่แก้ว (ดูได้จากหน้าออเดอร์เพราะออเดอร์รางวัลมีหมายเหตุกำกับ)
